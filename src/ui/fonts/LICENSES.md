# Fonts bundled with R9-SI and the R9 Studio

The fonts are embedded in the HTML (no request leaves the player's browser for them). All of them are published under the
SIL Open Font License 1.1 (https://openfontlicense.org): Orbitron (The Orbitron Project Authors), Rajdhani (Indian Type
Foundry), Sora (The Sora Project Authors), JetBrains Mono (The JetBrains Mono Project Authors). The OFL allows bundling and
redistribution with software; the fonts themselves are not sold.
