# F4 · Klang — plan (8 Oct 2026, branch f-sound, base v041)

Spec: docs/superpowers/specs/2026-10-08-realism-wave-design.md, section F4. Everything synthesized in Web Audio,
no samples, no external files, no requests. Player-facing text: none added (the Audio tab keeps its four sliders).

## What

1. **Material families** (11): grass, dirt, stone, wood, sand, snow, gravel, metal, carpet, water, glass. Every block
   type maps to exactly one family (the block name first — dirt is `sound: 'gravel'` in the registry, so the name wins —
   then the `sound` key). A node test walks the whole registry.
2. **Footsteps**: one recipe per family (band-limited noise plus a soft body thump). Pitch varies ±6 %, two timbre
   variants (heel / toe), speed sets the gain and brightness, sprint is louder, crouch is ×0.4 and darker.
3. **Place / break / progress**: a hit voice per family — thock (wood), clack (stone), tink (glass), thud (dirt),
   ding (metal), plus pat (grass), shh (sand), pff (snow, carpet), crunch (gravel), plop (water). Breaking progress
   is a faint crackle (three micro-clicks, every 0.25 s from the existing dig timer). The last hit adds a pop with a
   pitch rise, 320 → 980 Hz in 70 ms.
4. **UI**: click (30 ms), pling (≤ 60 ms, two partials), bonk (≤ 60 ms, refusal), rustle (≤ 60 ms, four grains).
   Every UI voice peaks at 0.126 (−18 dBFS) and is never positional and never in the reverb.
5. **Space**:
   - positional voices (StereoPannerNode + inverse-distance gain, silent beyond 48 blocks) for mobs (hurt), villagers,
     doors and machines;
   - occlusion: a voice whose source cell is darker than the listener's cell (sky light difference, the light field)
     goes through a lowpass (down to 1.2 kHz);
   - one convolver as the room: indoors the world voices send into it (room send 0.55), in caves a longer, darker
     impulse (swapped while the send is muted, so no click), outdoors the send is 0;
   - under water the world voices pass a lowpass at 900 Hz.
6. **Music**: pentatonic, three voices (pad, pluck, bass). Seeded by the game day: transposition, mode (major by day,
   minor at night) and the motif all come from `mulberry32(day)`, so every day differs and a day repeats. A hostile
   mob within 24 blocks ducks the music bus (−12 dB, 1.5 s glide). A villager within 30 blocks adds a soft tick
   rhythm. The Musik slider (volMusic) stays the only level control; at 0 no note is scheduled.
7. **Budget**: the persistent graph is 40 nodes or fewer (measured); a footstep or hit is 8 nodes or fewer, freed
   when it ends; at most 24 world voices alive at once (the next one is dropped); `listen` and `frame` allocate
   nothing (numbers only, a 4 Hz timer for the entity scans).

## Files

- `src/main/klang.js` (new, pure): families, recipes, the mapping, UI specs, the pentatonic plan, the seeded RNG.
- `src/main/audio.js`: the graph (sfx → muffle → master, room send → convolver, music → duck), `step`, `dig`, `place`,
  `play` (UI names and `opts.at`), `listen`, `updateMusic` (pentatonic, seeded, duck, village tick), `stats`, `state`.
- `src/main/player.js`: `step` gets speed, crouch and sprint (one line).
- `src/main/game.js`: `listen` each frame; `updateMusic` gets hostile mobs, villagers and the day (two lines).
- `src/main/sim.js`, `src/main/entities.js`, `src/main/villages.js`: `opts.at` on door, machine and mob-hurt sounds.
- `build.js`: `klang` in MAIN before `audio`. `test/regress.sh`: `klang.js` in NODE_SET, `sound.mjs` in BROWSER_SET.
- Tests: `test/klang.js` (node, stubbed AudioContext), `test/sound.mjs` (browser).

## How measured

- **Node graph** (stub context, numbers recorded in the test output): persistent nodes after `init`; nodes per
  footstep, per hit, per UI click, per music bar; live nodes after 60 s of play with music and ambience on.
- **Audio thread**: no GPU work is added, so the render passes are unchanged on every preset. The global convolver's
  impulse goes from 2.8 s to 1.3 s (room) and 2.6 s (cave), so the convolution work per sample on the audio thread
  is lower. The number is written in the final report from the IR lengths, not guessed.
- **Main thread** (per frame): `listen` + `updateMusic` timed around 600 frames in node (`performance.now`). Very Low
  must not be slower than the old `updateMusic` path; the old path is timed the same way from `git show HEAD:`.
- **Allocation**: the node count across 600 idle frames with music off must not change.
- **Browser** (`sound.mjs`): `audio.stats()` before and after each action (walk on four materials, place and break
  three, open a door, go indoors, music on and off), `audio.state()` for the lowpass and room send, page errors = 0.

## Risks

- Headless Chromium may not run the audio clock. The test checks the logic (families, nodes, filter values, the
  event log) and not the heard output, so it does not depend on the clock.
- The convolver IR swap clicks if the send is not muted first. The swap waits 90 ms after the mute.
- `game.js`, `player.js` and `sim.js` are touched by other fronts: each edit is one line or one argument.
