# W2 „Bauhand & ✨" — plan (2026-10-08)

Spec: `docs/superpowers/specs/2026-10-07-all-ages-workflow-design.md` §4 (Bauhand), §5 (wizard), §8 (W2 tests). Owner
decisions: both mouse buttons place a held Ding · 🏗 Bauen opens the Karte · the spawn point is „mein Platz".
Coordinator: the Bauhand owns B and exposes `VR.Bauhand.addAction({id, icon, label, when(target), run(target)})`
(another agent's ✏️ live-edit hooks in there); the wizard's „Wie?" uses the R9 Forge and the Genie / Baukasten, so a
child makes a skyscraper, a bridge, a castle, a park or a sofa in three clicks (Was? → Wie? → Wohin?).

## Architecture

- **`src/main/bauhand.js`** (game, new) — `VR.Bauhand`: one dispatcher for B (a `Game.prototype.handleKeys` wrapper;
  Esc / Enter / R / Z / 1–8 / arrows while open or holding), the ring (DOM over the canvas: target card on top,
  „✨ Neu…", 8 slots = ★ and made things newest first, else the starter set ☆; „▸ alle"), holding (strip above the
  hotbar, wheel / R turn, both buttons place, LMB never breaks, Z takes it back), the ghost (`Gadgets.outlines`
  wrapper: lot outline, footprint grid that glows, height box; red dashed + one reason when not ok; a ✓/✕ chip at the
  crosshair), placing = a plan in `r9si.plans.<w>` built at once through `Blueprints.tryBuild` (kinds house · model ·
  forge · piece), the failure cases of §4, Survival / guest / vehicle, hints 4–7, the soft „pling".
- **`src/main/blueprints.js`** (modify) — `kind:'piece'` plans (a Bauteil from `r9si.library`, pal + RLE),
  `settle:true` (the floor is found when the ground is loaded — „An meinem Platz" from anywhere), `tryBuild(pl)`
  pulled out of `tickPlans` (the Bauhand builds at once, `tickPlans` does the rest), `cancelSlices()`, and
  `storePlans` says whether the browser kept it.
- **`src/shared/isopic.js`** (new, both pages) — `VR.IsoPic`: a software isometric picture of ops or a grid into an
  RGBA buffer (no WebGL, no canvas needed — node tests hash it); cheap enough for six variants on a slow PC.
- **`src/shared/wizkinds.js`** (new, both pages) — `VR.WizKinds`: the Was? tiles and, per kind, the six variants:
  Forge kinds (Hochhaus, Burg, Brücke, Park, Turm, Halle, Stadion, Mauer, Raumschiff) via `Forge.variants`; 🏠 Haus =
  six Baukasten houses (`HK.random` with a seeded RNG); Genie kinds (Fahrzeug, Tier, Figur, Natur, Ding) = six
  things of the kind, a named thing = itself + five colour / feature variants; 🛋 Möbel = VM models by kind; a typed
  wish → the kind it names (`Forge.typeOf`, else `GenieBrain.design`). Pure data + functions (node-tested).
- **`src/shared/wizard.js`** (new, both pages) — `VR.Wizard`: the one dialog „Was? › Wie? › Wohin?" (progress row,
  ← on every step, Esc closes, keyboard: Tab / arrows / Enter / 1–6), pictures filled one per frame, „✨ Sag, was
  anders sein soll", 🎲 „andere sechs", Weiter saves into 🎒 Meins (Genie → `g:` + Bauteil `p:` with
  `origin.kind 'genie'`; Baukasten → `k:` + `p:`; Forge → `f:<dna>` ★), nothing touches the world before Wohin?.
  A page plugs in a host: `{ pic(thing) → Promise<{ops|grid}>, colors, where: [...], place(where, thing) }`.
- **`src/main/wizard_game.js`** (new) — the game's host: Forge pieces from the game's worker, Genie / Baukasten from
  the Studio's own modules bundled lazily (`VR.GenieLazy()`: colors · housekit · genie_brain · genie, compiled only
  when ✨ is first used), Wohin? = 🧍 Vor mir (the Bauhand holds it; from the start screen `r9si.hand` + ▶) ·
  📍 An meinem Platz (a settled plan 6 blocks before the spawn, a landing record, ▶ / the reveal flight) · 🗺 Auf
  der Karte (the Studio's Karte with it in hand). The start screen's ✨ tile opens it there.
- **`src/studio/wizard.js`** (new) — the Studio's host: the ✨ tile and `#erschaffen` open the same wizard;
  Wohin? → the game under the overlay holds it / `r9si.hand` / a plan at mein Platz / the Karte tool (forge, piece).
- **`src/ui/bauhand.css`** (new) — ring, strip, chip, wizard; appended to both stylesheets.
- Small edits: `build.js` (bundles), `src/shared/ding.js` (`f:` Dings), `src/main/start.js` (`r9si.hand` → the
  Bauhand), `src/main/renderer.js` (outline segments for dashes), `src/studio/colors.js` (texture host in the game),
  `src/studio/world.js` + `studio_worker.js` (a `piece` tool on the Karte), `lang_de.js` / `lang_en.js`.

## Review focus

1. Two owners of B → one dispatcher (`handleKeys` wrapper), tested: B in a vehicle, in chat, on a screen does nothing.
2. LMB while holding never breaks a block; the wheel never scrolls the hotbar while holding.
3. Z after a placement takes exactly that placement back (also a sliced Forge build still running), and the plan
   leaves `r9si.plans`.
4. „Kein Platz hier": a red ghost and a click that changes nothing (blocks in the way, standing on the lot).
5. Nothing touches the world or the plans before Wohin? (wizard test).
6. Low-end: the ring and the wizard do no per-frame DOM work; pictures one per frame; the Genie code compiles only
   when ✨ is used.
