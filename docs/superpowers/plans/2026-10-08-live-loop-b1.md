Spec: `docs/superpowers/specs/2026-10-03-live-loop-design.md` (§2, §3, §5, §6). Owner decisions: looks global per

## Order (each step: failing test → code → green → commit)

1. `looks_core.js` → `looks.js` + mesher bit 15 → `mesh_same.js` green.
2. `variants_core.js` → `blocks_var.js` + fill → `id_snapshot.json` appended once, `modern_pack.js` end check excludes the slots.
3. Game side (liveloop.js, shaders, renderer table, icons, held item, worker message, remesh scan, world backup, pause menu, Bauhand hook).
4. MP pack + PROTO 2.
5. Studio panel + route + ✏️ on cards + Möbel palette.
6. `test/liveloop.mjs` (overlay recolour → game within one remesh, Studio preview, Original reverts; Als Variante fills a slot, placing works, a saved world reloads with it; a guest receives the host's looks); shots `test/shots/live_*.png`.
7. `REGRESS_ONLY=node bash test/regress.sh`, the touched browser tests (studio_live, catalog, mp, smoke), report.

## Budgets („Sehr niedrig")

Apply ≤ 2 ms for tables; the remesh scan ≤ 20 ms per 81 columns, 8 a frame; the luminance table only when a look
uses `rc` (measured); slots ≈ 0.5 MB of tables per thread, no GPU texture layers.
