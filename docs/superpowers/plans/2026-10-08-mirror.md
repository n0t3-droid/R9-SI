# 🪞 Spiegel-Bauen (wave 2, W-C) · Implementation Plan

**Goal:** every block the player places or breaks by hand in Kreativ / Zen is mirrored — X, Z, 4-fach (X+Z) or 8-fach (rund,
the eight symmetries of a square) — with its state mirrored too, and a faint glowing axis shows where the mirror is.

**Spec:** `docs/superpowers/specs/2026-10-08-new-era-wave2-design.md` § W-C, refined below where the code shows a better way.

## Decisions (and where they differ from the spec)

- **Key ⇧M, not M.** M already opens the Weltkarte in every mode (⚙ Tasten „M Karte", the map's own note „M schließt",
  the loading tip „M öffnet die Weltkarte"). Taking M in Kreativ would hide the map from exactly the players who fly
  around most, and M would mean two things by mode. ⇧M keeps the mnemonic (M), keeps the map, and in Überleben it gives
  the kind hint („ein Werkzeug für Kreativ und Zen"). The HUD chip is a button (Einfach and Profi), the pause menu's
  creative tools get the same button (reachable with a locked mouse), and `/spiegel x|z|4|8|aus` (`/mirror`) sets a mode
  directly with the centre where you point (re-centring without cycling through all modes). `/spiegel` is a Profi command (the Einfach chat takes only its friendly commands): in Einfach the chip re-centres, from aus with ⇧M.
- **Centre:** the block you point at; on the face you look at, aiming within a quarter block of an edge puts the axis
  *between* the two blocks there (even widths), anywhere else *on* the block (odd widths). Stored doubled (`c2x, c2z`:
  odd = on a block, even = between). 8-fach needs both on or both between; a mixed centre snaps the between-coordinate
  onto its block. No target: the block under the player.
- **Undo:** hand edits have no undo in this game (the wand/blueprint undo is separate) — none invented.
- **Copies** go through `world.setBlock(…, 4)` like the hand's own edit: saved (`c.modified`), sent in multiplayer (the
  world listener `mp.onBlockChanged`), sim/villages notified. No sound or particles per copy (the hand's once); the
  guide pulses once. Max 7 copies per action (8-fach), each a whole piece (door, bed, tall plant, VM model).
- **Skipped copies:** a cell that is not replaceable (except a single slab of the same type that becomes double), that
  overlaps the player (the hand's own collision test, moved into `Player.placeBlocked`), an entity, an unloaded column,
  a plant without soil. A piece is copied whole or not at all.
- **Breaks:** at each mirrored spot whatever is there (not air, not fluid) — symmetric digging works too; a multi-cell
  piece first looks for a cell of the same type in its mirrored footprint, and `g.breakMulti` takes the rest.
- **States** (`VR.Mirror.state`): FACING4/6 and hopper facings by the transform's direction map; `axis` x↔z on quarter
  turns and diagonals; `rotation` (16) generic; `hinge` and `_l/_r`, `_vl/_vr` parts (low hip roofs) swap on reflections;
  `faces` bit masks (vines, lichen) permuted; torch `face` 1..4; stem `attach`; rail `shape` (straights, slopes,
  curves); beds/doors/tall plants per cell (their parts stay consistent). VM models (sofas, beds, windows …): quarter
  turns per cell (part index kept, facing turned — exact); reflections re-anchor the model with the mirrored facing on
  the mirrored bounding box (exact for left/right-symmetric models, the facing rule otherwise). Stair corners, fence,
  wall, pane and roof joins are recomputed by the mesher from the neighbours as always. Anything else keeps its props.
- **Axis:** `renderer.drawGuide` — the line program (`P.line`), its own small VBO filled when the mirror changes (not per
  frame), three draws (a wide faint halo strip and a thin bright core on the ground, 2 × 20 blocks; a translucent
  vertical plane 12 blocks high that pulses after an edit), depth-tested, no depth writes. Off with the mode, F1, photo.

## Files

- Create `src/shared/mirror.js` (`VR.Mirror`, pure; SHARED + `test/load_shared.js`), `src/main/mirrorbuild.js`
  (`VR.MirrorBuild`: mode, centre, edits, chip, guide geometry; MAIN before `game`), `test/mirror.js`, `test/mirror.mjs`.
- Modify `src/main/player.js` (hooks in `afterPlace` / hand `breakBlock`, `placeBlocked`), `src/main/game.js` (create,
  ⇧M, `/spiegel`, render field, help), `src/main/renderer.js` (`drawGuide`), `src/main/ui.js` (pause button),
  `src/ui/style.css` (chip), `lang_de.js` / `lang_en.js` (`g.mirror.*`), `test/SUITE.md`, `test/regress.sh` (node set).

## Steps

1. `test/mirror.js` (node, failing first): transforms and positions (centre on / between blocks, 4-fach, 8-fach with no
   duplicates on the axes and the diagonals), the state table for every directional kind × every transform, VM pieces,
   rails, faces, hip parts; every mirrored state is a valid state of the same type.
2. `src/shared/mirror.js` until green; commit.
3. `mirrorbuild.js` + hooks + chip + command + i18n keys; `test/lang.js` green; commit.
4. `drawGuide` + guide geometry; commit.
5. `test/mirror.mjs` (de-DE, after the release regression): ⇧M → 4-fach → stairs and a door → four each with the right
   facings / hinges; break one → its copies go; aus → single; the axis is drawn (draw counter and cyan pixels); no page
   errors; a symmetric little house → `test/shots/mirror_1..3.png` (looked at). Then node regression, smoke, doors,
   player2.
