# Plan: the ✨ Modern Living tab opens without a hitch (iconperf)

## Measured (v0.40, browser, 236 items, debug run through test/wt_run.sh)
- One frame held 203 ms of icon work: `vm_garden_hammock_stand` 188 ms in its lazy build (`materialize`) and 10 ms in
  `VM.icon`. Next: fridge 79 ms (build 27 + icon 33), rattan divider 56 ms (build 51).
- All icon paints: 2.0 s in total = builds 0.95 s + `VM.icon` about 1.0 s + drawing.
- `VM.icon` (src/shared/voxmodel.js) samples the whole span³ box through `m.get`, once per icon: up to 16 M calls for a
  large model. Node: 843 ms for the 236 items.
- `Builder.extrude` (src/shared/voxmodel.js) runs the point-in-polygon test for every voxel of every layer. The 2-D
  result does not depend on the layer: the hammock (168 edges, 6 layers) makes 2 M edge tests.
- The lazy build runs synchronously on the first paint of a model, with no budget (since v0.40 the pack is no longer
  built at boot, which is why the tab got slow; at v0.39 the pack was built before the tab opened).
- `VX.init` is not the cause (0 ms, already done at world creation). `Icons.face()` is not used by the tab (0 paints).

## Root causes
1. `VM.icon` visits every empty cell of the span box. It only needs the occupied voxels.
2. `Builder.extrude` repeats the 2-D inside test per layer.
3. A model's first paint builds the model in the same frame, and the pump starts a new paint whenever the frame has
   less than 6 ms used, so a cold model can sit next to other paints.

## Changes (each keeps every voxel and icon cell; test/icon_same.js holds the reference)
- A. `VM.icon`: one pass over the model's voxels into the 8³ bins (same sums, flags and threshold). The sampling loop is
  kept as the fallback for a grid that is not integral.
- B. `Builder.extrude`: the inside mask is computed once per call and reused for every layer.
- C. `VR.IconPump` (src/main/icons.js) replaces the ad-hoc pump in ui.js: at most 6 ms of paints per frame; a model that
  is still to be built is painted alone in its frame; detached canvases are skipped without cost.
- D. `Icons.cold(id)`: true while the picture is not cached and the model is still lazy.
- E. `VR.iconWarm` (src/main/icons.js): idle-time pre-warm of the Modern Living pictures through VM.prewarm, one per
  idle slice, never before 10 s of play (started with the model pre-warm in game.startPrewarm).
- F. Studio 🧱 Teile ✨ Modern chip: measured first (test/_dbg_studio.mjs, a throwaway); fixed the same way if the
  cause is shared (the build) and the per-frame cost of the picture pump (studio/catalog.js pumpModels).
