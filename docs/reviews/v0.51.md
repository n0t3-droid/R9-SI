1. ## Lessons for the process
1. **Every front fills its self-review before the merge** — f-sky4's §6 is empty; the coordinator's gate should refuse an empty §6.
2. **The names list is a merge gate**: `names.js` should fail when a table value carries a capitalised invented word not in its list (a heuristic over new keys).
3. **Very Low means every place, also orbit and moons**: the bench compares all six places against the previous tag at every release.
4. **The adventurer session is the release's test of its headline** — run it on the merged release before the critic.
5. **This review's cost:** four browser runs, ~50 min of the release lane in all on a quiet machine (v0.49: ~3 h under load) — the quiet lane pays.
